# 成本控制与预算管理制度

## 第一章 总则

### 第一条 目的与依据

为规范公司成本控制与预算管理，建立科学、规范、高效的成本预算管理体系，强化成本意识，优化资源配置，降低运营成本，提高经济效益，确保公司经营目标实现，根据《中华人民共和国会计法》《企业会计准则》等法律法规，结合公司实际情况，特制定本制度。

### 第二条 适用范围

本制度适用于公司总部及各生产基地、分公司、子公司的成本控制与预算管理活动，涵盖生产、研发、销售、管理等所有业务领域。

### 第三条 管理原则

成本控制与预算管理遵循以下原则：

1. **战略导向原则**：预算管理以公司发展战略为导向，确保资源配置与战略目标一致。
2. **全面预算原则**：实行全面预算管理，覆盖所有业务、所有部门、所有项目。
3. **目标管理原则**：以成本目标和预算目标为核心，层层分解，落实责任。
4. **过程控制原则**：加强预算执行过程监控，及时发现偏差，采取纠偏措施。
5. **权责对等原则**：谁使用资源谁负责成本，谁审批预算谁负责控制。
6. **持续改进原则**：通过成本分析和预算复盘，持续优化成本结构，提高资源效率。
7. **刚性约束原则**：预算一经批准，具有刚性约束力，严格按预算执行。

### 第四条 术语定义

1. **成本**：企业为生产产品、提供劳务而发生的各种耗费，包括直接材料、直接人工、制造费用等。
2. **期间费用**：企业当期发生的、不能直接或间接归入产品成本的费用，包括管理费用、销售费用、研发费用、财务费用。
3. **预算**：企业在一定时期内对经营活动、投资活动、财务活动等作出的预期安排，包括业务预算、资本预算、财务预算。
4. **全面预算**：以企业战略目标为导向，对一定时期内企业的各项资源和经营活动进行全面预测、规划和控制的管理活动。
5. **预算编制**：根据企业战略目标和经营计划，编制各项预算的过程。
6. **预算执行**：各部门按预算组织开展业务活动，控制预算支出的过程。
7. **预算调整**：在预算执行过程中，因客观条件变化对预算进行修改的过程。
8. **预算考核**：对预算执行结果进行评价和考核，与绩效挂钩。
9. **标准成本**：在正常生产经营条件下，产品应达到的成本水平，是成本控制和成本分析的基准。
10. **差异分析**：将实际成本与标准成本或预算成本进行对比，分析差异原因的过程。

## 第二章 组织与职责

### 第五条 预算管理委员会

公司设立预算管理委员会，作为预算管理的最高决策机构。

**组成**：
- 主任：总经理
- 副主任：财务总监
- 成员：各副总经理、各部门负责人

**职责**：
1. 审议公司预算管理制度和预算管理办法。
2. 审议公司年度预算目标和预算编制方针。
3. 审议公司年度总预算和部门预算。
4. 协调解决预算编制和执行中的重大问题。
5. 审批预算调整方案。
6. 审议预算执行情况报告和预算考核结果。
7. 决定预算管理的其他重大事项。

预算管理委员会每季度召开一次会议，审议预算执行情况。遇重大事项可临时召开。

### 第六条 财务部

财务部是公司成本控制与预算管理的归口管理部门，主要职责：

1. 贯彻执行国家财经法规和公司预算管理制度。
2. 负责制定和修订公司成本预算管理制度。
3. 负责组织公司年度预算编制工作，汇总编制公司总预算。
4. 负责预算下达、执行监控和分析。
5. 负责成本核算和成本分析，提供成本管理信息。
6. 负责标准成本制定和维护。
7. 负责预算调整审核和预算考核。
8. 负责成本控制措施的制定和监督实施。
9. 负责成本预算管理培训和指导。
10. 负责成本预算文档管理和档案保存。

### 第七条 各业务部门

各部门是本部门成本控制与预算管理的责任主体，主要职责：

1. 负责本部门预算编制，提供准确的预算基础数据。
2. 负责本部门预算执行，严格按预算控制支出。
3. 负责本部门成本控制，落实成本降低措施。
4. 负责本部门预算执行情况分析，及时发现和解决问题。
5. 配合财务部进行成本核算和成本分析。
6. 提出预算调整申请，说明调整原因和影响。
7. 参与预算考核，落实考核结果。

各部门负责人是本部门成本预算管理第一责任人。

### 第八条 生产部门

1. 负责生产成本控制，包括材料消耗、工时消耗、制造费用控制。
2. 负责生产计划执行，提高生产效率，降低单位产品成本。
3. 负责在制品和库存管理，减少资金占用和浪费。
4. 负责设备维护保养，降低设备维修费用。
5. 负责能源消耗控制，降低能耗成本。
6. 参与标准成本制定，提供实际成本数据。

### 第九条 采购部

1. 负责采购成本控制，通过比价、招标、谈判等方式降低采购价格。
2. 负责供应商管理，优化供应链，降低采购成本。
3. 负责采购预算执行，控制采购支出。
4. 负责物料跟催，减少紧急采购和额外费用。
5. 参与物料选型和成本分析，协助降低产品成本。

### 第十条 研发中心

1. 负责研发费用预算编制和执行控制。
2. 负责产品设计成本控制，通过优化设计降低产品成本。
3. 负责研发项目成本核算和分析。
4. 参与标准成本制定，提供技术参数和物料清单。
5. 负责新工艺、新技术应用，降低制造成本。

## 第三章 预算编制

### 第十一条 预算编制周期

1. **年度预算**：每年编制一次，预算期为一个会计年度（1月1日至12月31日）。
2. **季度预算**：每季度编制一次，将年度预算分解到季度。
3. **月度预算**：每月编制一次，将季度预算分解到月度，作为执行和控制的依据。

### 第十二条 预算编制内容

公司全面预算包括以下内容：

1. **业务预算**：
   - 销售预算：销售收入、销售数量、销售价格、销售费用。
   - 生产预算：生产数量、产品结构、生产进度。
   - 采购预算：采购数量、采购价格、采购金额、采购费用。
   - 人工预算：人员编制、工资总额、社保公积金、培训费用。
   - 制造费用预算：设备折旧、维修费用、能源费用、车间管理费用。
   - 研发预算：研发项目、研发费用、研发人员费用。
   - 管理费用预算：办公费用、差旅费用、招待费用、折旧摊销等。
   - 财务费用预算：利息支出、手续费、汇兑损益等。

2. **资本预算**：
   - 固定资产投资预算：设备购置、厂房建设、信息化建设。
   - 无形资产投资预算：软件购置、专利申请、技术引进。
   - 对外投资预算：股权投资、债券投资等。

3. **财务预算**：
   - 现金预算：现金收入、现金支出、现金余缺、资金筹措。
   - 预计利润表：营业收入、营业成本、期间费用、利润。
   - 预计资产负债表：资产、负债、所有者权益。
   - 预计现金流量表：经营活动、投资活动、筹资活动现金流量。

### 第十三条 预算编制程序

公司预算编制采用"自上而下、自下而上、上下结合"的程序：

1. **预算启动**（每年10月初）：
   - 预算管理委员会确定下年度预算目标和编制方针。
   - 财务部发布预算编制通知和预算编制模板。
   - 召开预算编制启动会，部署预算编制工作。

2. **部门预算编制**（10月-11月）：
   - 各部门根据公司预算目标和本部门工作计划，编制本部门预算。
   - 部门预算应详细说明预算编制依据、计算方法、保障措施。
   - 部门预算经部门负责人审核后提交财务部。

3. **预算汇总审核**（11月-12月初）：
   - 财务部汇总各部门预算，编制公司总预算草案。
   - 财务部对各部门预算进行审核，提出修改意见。
   - 与各部门沟通协调，调整预算。
   - 形成公司总预算草案。

4. **预算评审**（12月中旬）：
   - 预算管理委员会对公司总预算进行评审。
   - 各部门汇报本部门预算。
   - 评审委员会提出修改意见。
   - 根据评审意见修改完善预算。

5. **预算批准**（12月底）：
   - 修改后的预算报总经理办公会审议。
   - 审议通过后报董事会审批（如需）。
   - 批准后正式发布下年度预算。

6. **预算下达**（次年1月初）：
   - 财务部将批准后的预算下达至各部门。
   - 各部门将预算分解到季度和月度。
   - 预算正式开始执行。

### 第十四条 预算编制方法

公司根据不同预算项目的特点，采用以下预算编制方法：

1. **增量预算法**：以上年度预算执行数为基础，结合下年度变化因素调整编制。适用于相对稳定的常规费用项目。
2. **零基预算法**：不考虑上年度预算，一切从零开始，根据实际需要编制预算。适用于管理费用、销售费用等可控费用项目。
3. **弹性预算法**：根据不同业务量水平编制多档预算，适应业务量变化。适用于制造费用、销售费用等与业务量相关的费用。
4. **滚动预算法**：预算期连续滚动，每过一个月或一个季度，补充新的预算期。适用于需要动态调整的预算项目。
5. **作业预算法**：基于作业活动和成本动因编制预算。适用于间接费用和共享费用的分摊。

### 第十五条 预算编制要求

1. **目标一致性**：部门预算应与公司战略目标和年度经营目标一致。
2. **数据准确性**：预算编制应以准确的基础数据为依据，不得随意估算。
3. **内容完整性**：预算应覆盖本部门所有业务活动和支出项目，不得遗漏。
4. **计算合理性**：预算计算方法应科学合理，计算过程清晰可追溯。
5. **措施保障性**：预算应配套相应的保障措施，确保预算目标可实现。
6. **时间及时性**：各部门应按规定时间提交预算，不得拖延。

## 第四章 预算执行与控制

### 第十六条 预算执行

1. 预算一经批准下达，各部门必须严格执行，不得超预算支出。
2. 各部门应将预算目标层层分解，落实到具体项目、具体岗位、具体人员。
3. 各项支出必须有预算依据，无预算不得支出。
4. 预算执行中应坚持"先预算后支出、先审批后使用"的原则。
5. 各部门应建立预算执行台账，及时记录预算支出情况。

### 第十七条 预算控制

公司实行分级预算控制：

1. **总额控制**：各部门年度预算总额不得突破。
2. **项目控制**：各预算项目之间不得随意调剂，确需调剂的按程序审批。
3. **进度控制**：预算支出进度应与业务进度匹配，防止前松后紧或突击花钱。
4. **审批控制**：各项支出按审批权限逐级审批，超权限不得审批。

**预算支出审批权限**：
| 支出金额 | 审批权限 |
|----------|----------|
| 1000元以下 | 部门负责人审批 |
| 1000-10000元 | 分管领导审批 |
| 10000-50000元 | 财务总监审批 |
| 50000元以上 | 总经理审批 |

### 第十八条 预算执行监控

1. 财务部建立预算执行监控机制，实时监控预算执行情况。
2. 每月编制预算执行情况报表，反映各部门预算执行进度和偏差。
3. 对预算执行偏差超过10%的项目，进行重点分析和预警。
4. 对可能超预算的部门，提前发出预警，督促采取控制措施。
5. 预算管理委员会每季度审议预算执行情况，研究解决预算执行中的问题。

### 第十九条 预算执行分析

1. 各部门每月对本部门预算执行情况进行分析，形成预算执行分析报告。
2. 分析内容包括：
   - 预算执行进度和偏差。
   - 偏差原因分析（主观原因、客观原因）。
   - 采取的控制措施和效果。
   - 后续预算执行预测。
   - 需要协调解决的问题。
3. 财务部汇总各部门分析报告，形成公司预算执行分析报告。
4. 预算执行分析应实事求是，数据准确，原因分析深入，措施具体可行。

## 第五章 预算调整

### 第二十条 预算调整原则

1. 预算一经批准，原则上不予调整，保持预算的严肃性和刚性。
2. 确因客观条件发生重大变化，导致预算无法执行的，可按程序申请调整。
3. 预算调整应遵循"先有预算后有支出"的原则，未批准调整前不得超预算支出。
4. 预算调整应兼顾需要与可能，确保公司整体预算目标实现。

### 第二十一条 预算调整条件

符合下列条件之一的，可申请预算调整：

1. 国家政策、法律法规发生重大变化，对公司经营产生重大影响。
2. 市场环境发生重大变化，如主要客户、主要供应商、市场价格发生重大变化。
3. 公司战略或经营计划发生重大调整。
4. 发生不可抗力事件，如自然灾害、重大疫情等。
5. 组织机构或业务范围发生重大调整。
6. 其他经预算管理委员会认定的重大变化。

### 第二十二条 预算调整程序

1. **调整申请**：需要调整预算的部门，向财务部提交《预算调整申请单》，说明调整原因、调整内容、调整金额、影响分析。
2. **审核评估**：财务部对调整申请进行审核，评估调整的必要性和合理性，提出审核意见。
3. **分级审批**：
   - 部门内部预算项目调剂，金额在5万元以下的，由财务总监审批。
   - 部门预算总额调整或金额在5-50万元的，由总经理审批。
   - 金额在50万元以上或公司总预算调整的，由预算管理委员会审议，总经理审批，必要时报董事会。
4. **预算下达**：预算调整批准后，财务部下达调整后的预算，各部门按调整后预算执行。
5. **调整记录**：预算调整应记录在案，作为预算考核的依据。

### 第二十三条 预算调剂

1. 各部门内部预算项目之间的调剂，由部门提出申请，财务部审核，财务总监审批。
2. 部门之间的预算调剂，由调入部门提出申请，调出部门同意，财务部审核，总经理审批。
3. 预算调剂不得改变预算总额，不得将专项预算调剂为通用预算。
4. 预算调剂应在预算执行中期（6月底）集中办理，特殊情况可随时申请。

## 第六章 成本控制

### 第二十四条 成本控制目标

公司成本控制总体目标：

1. 产品成本逐年降低，年度成本降低率不低于3%。
2. 期间费用率逐年下降，管理费用率控制在5%以内，销售费用率控制在8%以内。
3. 研发费用率保持在5%-8%，提高研发投入产出比。
4. 采购成本逐年降低，年度采购降本率不低于2%。
5. 能源消耗逐年降低，单位产值能耗下降率不低于3%。

各部门根据公司总体目标，制定本部门成本控制目标。

### 第二十五条 生产成本控制

1. **材料成本控制**：
   - 制定材料消耗定额，严格按定额发料。
   - 推行限额领料制度，超限额领料需审批。
   - 加强材料使用过程监控，减少浪费和损耗。
   - 提高材料利用率，开展边角料回收利用。
   - 优化产品设计，减少材料用量。
   - 定期进行材料消耗分析，查找浪费原因。

2. **人工成本控制**：
   - 优化人员配置，提高劳动生产率。
   - 制定工时定额，按定额组织生产。
   - 加强培训，提高员工技能和操作熟练度。
   - 推行绩效考核，将效率与薪酬挂钩。
   - 优化生产组织，减少停工待料和无效劳动。
   - 控制加班，提高正常工作时间效率。

3. **制造费用控制**：
   - 设备维护保养，减少故障维修费用。
   - 提高设备利用率，减少设备闲置。
   - 能源消耗控制，节约水电气。
   - 车间管理费用控制，节约办公费用。
   - 低值易耗品管理，减少浪费。
   - 定期进行制造费用分析，控制费用支出。

### 第二十六条 采购成本控制

1. **价格控制**：
   - 建立价格数据库，掌握市场价格动态。
   - 推行招标采购、比价采购，通过竞争降低价格。
   - 与供应商谈判，争取优惠价格。
   - 集中采购，发挥规模优势。
   - 框架协议采购，锁定价格。
   - 定期进行价格分析，评估价格合理性。

2. **质量成本控制**：
   - 选择优质供应商，减少来料不合格。
   - 加强来料检验，防止不合格品流入生产。
   - 减少因物料质量问题导致的返工、报废。
   - 与供应商签订质量协议，明确质量责任。

3. **库存成本控制**：
   - 优化采购批量，减少库存积压。
   - 推行JIT采购，降低库存水平。
   - 加强库存管理，减少呆滞料。
   - 提高库存周转率，降低资金占用。
   - 定期清理呆滞料，减少损失。

4. **物流成本控制**：
   - 优化运输方式，降低运输费用。
   - 集中运输，提高装载率。
   - 选择优质物流商，降低货损。
   - 优化包装，减少包装费用。

### 第二十七条 研发成本控制

1. **项目预算控制**：
   - 研发项目立项时编制详细预算。
   - 严格按预算控制研发支出。
   - 定期进行研发费用分析，控制项目成本。
2. **设计成本控制**：
   - 推行价值工程，在满足功能前提下降低成本。
   - 优化产品设计，减少零部件数量和材料用量。
   - 推行标准化、通用化，降低采购和制造成本。
   - 加强设计评审，减少设计变更和返工。
3. **试制成本控制**：
   - 优化试制方案，减少试制次数。
   - 充分利用现有设备和资源。
   - 加强试制过程管理，提高一次成功率。
4. **研发效率提升**：
   - 加强项目管理，缩短研发周期。
   - 推行模块化设计，提高设计复用率。
   - 加强知识管理，减少重复劳动。
   - 引入先进设计工具，提高设计效率。

### 第二十八条 管理费用控制

1. **办公费用控制**：
   - 推行无纸化办公，减少纸张消耗。
   - 集中采购办公用品，降低采购价格。
   - 加强办公用品领用管理，减少浪费。
   - 控制办公设备购置和维修费用。
2. **差旅费用控制**：
   - 制定差旅费用标准，严格按标准执行。
   - 加强差旅审批，控制出差人数和天数。
   - 优先选择经济实惠的交通和住宿。
   - 推行视频会议，减少不必要出差。
3. **招待费用控制**：
   - 制定招待费用标准，严格按标准执行。
   - 加强招待审批，控制招待次数和标准。
   - 实行招待费用预算管理，总额控制。
4. **折旧摊销控制**：
   - 合理控制固定资产投资，避免闲置。
   - 加强资产管理，提高资产使用效率。
   - 合理选择折旧方法和摊销年限。

### 第二十九条 销售费用控制

1. **市场推广费用控制**：
   - 制定市场推广预算，严格按预算执行。
   - 优化推广渠道，提高投入产出比。
   - 加强推广效果评估，及时调整策略。
   - 集中采购广告资源，降低采购成本。
2. **销售人力成本控制**：
   - 优化销售团队配置，提高人均产出。
   - 推行绩效考核，将薪酬与业绩挂钩。
   - 加强销售培训，提高销售能力。
3. **物流费用控制**：
   - 优化发货方式，降低运输费用。
   - 集中发货，提高装载率。
   - 优化包装，减少包装费用和货损。
4. **售后服务费用控制**：
   - 提高产品质量，减少售后维修。
   - 优化服务网络，降低服务成本。
   - 加强服务人员培训，提高一次修复率。
   - 推行远程诊断，减少现场服务。

### 第三十条 财务费用控制

1. **资金管理**：
   - 优化资金结构，降低资金成本。
   - 加强资金计划，提高资金使用效率。
   - 加速资金回笼，减少资金占用。
   - 合理安排付款，争取信用期。
2. **融资成本控制**：
   - 选择低成本融资渠道。
   - 优化融资结构，降低综合融资成本。
   - 提前还款，减少利息支出。
3. **汇兑损益控制**：
   - 加强汇率风险管理，运用金融工具对冲风险。
   - 优化结算方式，减少汇兑损失。
4. **手续费控制**：
   - 选择手续费低的银行和支付方式。
   - 集中办理银行业务，减少手续费。

## 第七章 标准成本与差异分析

### 第三十一条 标准成本制定

1. 公司对主要产品实行标准成本管理。
2. 标准成本构成：
   - 直接材料标准成本：标准用量×标准价格。
   - 直接人工标准成本：标准工时×标准工资率。
   - 制造费用标准成本：标准工时×标准制造费用分配率。
3. 标准成本制定依据：
   - 产品设计图纸和物料清单。
   - 工艺文件和工时定额。
   - 材料消耗定额。
   - 历史成本数据。
   - 市场价格和预期变化。
4. 标准成本每年修订一次，遇重大变化及时调整。
5. 标准成本经财务部审核，总经理批准后发布执行。

### 第三十二条 成本差异分析

1. 财务部每月进行成本差异分析，将实际成本与标准成本对比。
2. 差异分类：
   - 直接材料差异：
     - 用量差异 =（实际用量-标准用量）×标准价格。
     - 价格差异 =（实际价格-标准价格）×实际用量。
   - 直接人工差异：
     - 效率差异 =（实际工时-标准工时）×标准工资率。
     - 工资率差异 =（实际工资率-标准工资率）×实际工时。
   - 制造费用差异：
     - 耗费差异 = 实际制造费用-预算制造费用。
     - 效率差异 =（实际工时-标准工时）×标准分配率。
     - 产量差异 =（预算工时-实际工时）×标准分配率。
3. 差异分析应深入分析原因，明确责任部门。
4. 对重大差异（超过标准成本5%），应进行专项分析。
5. 差异分析结果作为成本控制和绩效考核的依据。

### 第三十三条 成本分析报告

1. 财务部每月编制成本分析报告。
2. 报告内容包括：
   - 产品成本完成情况。
   - 成本差异分析。
   - 成本构成分析。
   - 成本趋势分析。
   - 同行业对比分析。
   - 存在问题和改进建议。
3. 成本分析报告提交管理层和相关部门。
4. 每季度召开成本分析会，研究成本问题，制定改进措施。

## 第八章 预算考核与奖惩

### 第三十四条 预算考核

1. 公司建立预算考核制度，将预算执行情况纳入部门和个人绩效考核。
2. 考核内容：
   - 预算目标完成率。
   - 预算执行偏差率。
   - 预算控制有效性。
   - 预算编制质量。
   - 预算分析及时性和质量。
3. 考核周期：月度跟踪、季度考核、年度总评。
4. 考核结果与部门绩效工资、个人绩效奖金、评优评先挂钩。

### 第三十五条 成本考核

1. 公司建立成本考核制度，将成本控制目标纳入部门考核。
2. 考核指标：
   - 产品成本降低率。
   - 材料利用率。
   - 劳动生产率。
   - 采购成本降低率。
   - 期间费用控制率。
   - 单位产值能耗。
3. 成本考核结果与部门和个人绩效挂钩。

### 第三十六条 奖励

有下列情形之一的，给予表彰和奖励：

1. 超额完成成本降低目标，成效显著的。
2. 预算执行良好，严格控制支出的。
3. 提出成本控制合理化建议，取得显著经济效益的。
4. 在成本管理创新中做出突出贡献的。
5. 长期坚持成本控制，成绩突出的部门和个人。

奖励方式包括：通报表扬、颁发奖金、优先晋升、授予荣誉称号等。

### 第三十七条 处罚

有下列情形之一的，视情节轻重给予批评教育、绩效扣分、行政处分：

1. 未完成成本控制目标，且无客观原因的。
2. 预算执行不力，严重超预算的。
3. 预算编制弄虚作假，数据严重失实的。
4. 违反预算审批程序，擅自支出的。
5. 铺张浪费，造成成本损失的。
6. 成本核算弄虚作假，隐瞒真实情况的。

情节严重构成犯罪的，移交司法机关处理。
